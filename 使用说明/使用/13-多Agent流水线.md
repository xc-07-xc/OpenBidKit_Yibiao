# 多 Agent 流水线

「多 Agent 流水线」把标书编写拆成 6 个阶段，由 7 个角色 Agent 依次协作，关键节点停下来等你确认。

## 适用场景

- 想从招标文件一路跑到投标文档初稿，而不是逐页手动操作
- 希望每一阶段都能人工把关，避免错误一路带到成稿
- 想观察多智能体如何分工、返工与自我修正

## 使用步骤

1. 打开侧边栏「多 Agent 流水线」。
2. 填写「项目概述」和「公司资质与已有材料概况」（都可以留空，但填了结果更准）。
3. 点击「上传招标文件（Word / PDF / TXT）」，解析结果会写入工作区。
4. 点击「启动流水线」，阶段卡片会依次变为执行中。
5. 到「待人工确认」的阶段，填写意见后选择：
   - **通过并进入下一阶段**
   - **打回重跑本阶段**（会清空本阶段产物重新执行）
6. 全部通过且质检通过后，可点击「导出投标文档（Word）」。

## 阶段说明

| 阶段 | 角色 | 是否需要确认 |
| --- | --- | --- |
| 文档解析与要求提取 | 要求提取 | 是（口径澄清） |
| 资格审查与材料匹配 | 资格匹配 | 是（材料缺口） |
| 技术分析 | 技术响应 | 否，与法规检索并行 |
| 法规与案例检索 | 法规案例 | 是（检索依据） |
| 投标文档生成 | 正文生成 | 是（成稿定稿） |
| 一致性检查 | 质量守门员 | 否，自动质检 |

## 自动返工

一致性检查发现「可自纠」的 high 级问题（前后口径矛盾、承诺与响应不符等）时，会自动把问题清单回传给生成阶段重写，最多 2 轮；超过上限转人工。

「材料缺失」类问题（缺报价、资质、业绩、人员、证书等）不会自动返工，因为这类问题需要你补材料，Agent 自己改不出来。

## 页头标识

- **LangGraph 编排**：Python 图编排服务已就绪，并行、条件回边、断点恢复按图执行。
- **内置编排**：没有找到 sidecar 或 Python 环境，自动回退到内置编排器，流程一致但少了图能力。

## 常见问题

**Q：启动后一直显示执行中？**
A：单个阶段要调用模型，长标书可能需要几分钟；页面会自动刷新阶段状态。

**Q：点「通过」提示运行已中断？**
A：应用重启后上一轮运行无法续跑，重新启动流水线即可（之前已通过的阶段产物仍在知识库「流水线产物」里）。

**Q：阶段产物去哪了？**
A：同时写入两处：工作区 `technical-plan/<stage>.json`，以及知识库「流水线产物」文件夹。
